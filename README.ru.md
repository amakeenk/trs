# trs

**trs** (от **TR**a**S**h) — безопасная CLI-утилита для перемещения файлов в корзину по спецификации XDG Trash.

## Почему trs?

- **Безопасность по умолчанию** — файлы попадают в корзину, а не в /dev/null
- **Соответствие XDG** — работает с GNOME, KDE и другими десктопными окружениями
- **Фокус на безопасность** — защита от атак через символические ссылки, path traversal и DoS
- **Без зависимостей** — чистый Go, никаких внешних утилит
- **Кросс-устройство** — автоматическая обработка файлов на разных файловых системах

## Использование

### Перемещение файлов в корзину

```bash
trs file.txt              # Переместить файл в корзину
trs file1.txt file2.txt   # Переместить несколько файлов
trs -r directory/         # Переместить директорию (рекурсивно)
trs -f nonexistent        # Принудительно (игнорировать несуществующие файлы)
trs -v file.txt           # Подробный вывод
```

### Список файлов в корзине

```bash
trs list                  # Показать все файлы в корзине
trs list --json           # Вывод в формате JSON
```

Вывод:
```
#  NAME              SIZE    DELETED              ORIGINAL PATH
1  config.json       1.2KB   2026-03-05 10:30    /home/user/project/config.json
2  old_backup/       45MB    2026-03-04 18:22    /home/user/backups/old_backup
```

### Восстановление файлов

```bash
trs restore              # Интерактивный TUI с нечётким поиском
trs restore config.json  # Восстановить по имени
trs restore 1            # Восстановить по индексу (из списка)
trs restore --last       # Восстановить последний удалённый файл
trs restore -f file.txt  # Перезаписать существующий файл
trs restore --json       # Вывод в формате JSON
```

### Очистка корзины

```bash
trs empty                # Очистить всю корзину
trs empty --days 7       # Только файлы старше 7 дней
trs empty --json         # Вывод в формате JSON
```

### Статус корзины

```bash
trs status               # Показать статистику корзины
trs status -v            # Подробно (старейший/новейший/крупнейшие файлы)
trs status --json        # Вывод в формате JSON
```

Вывод:
```
Trash: 42 files, 128.5 MB
```

С флагом `-v`:
```
Trash: 42 files, 128.5 MB
Oldest: 2026-02-01 10:00  Newest: 2026-03-10 15:30
Largest: backup.tar (50MB), video.mp4 (25MB), data.zip (10MB)
```

### Версия

```bash
trs version
trs version --json
```

### Автодополнение в оболочке

```bash
trs completion bash      # Bash
trs completion zsh       # Zsh
trs completion fish      # Fish
trs completion powershell # PowerShell
```

## Возможности

### Спецификация XDG Trash

- Домашняя корзина: `~/.local/share/Trash/`
- Корзина на томе: `$VOLUME/.Trash-$UID/`
- Автоматическая обработка перемещения между устройствами
- Совместимость с корзиной десктопного окружения

### Интерактивный TUI для восстановления

Команда `trs restore` запускает интерактивный терминальный интерфейс:
- Нечёткий поиск по именам файлов и оригинальным путям
- Навигация стрелками с предпросмотром в реальном времени
- Работает в любом терминале

### Безопасность

trs реализует множество мер безопасности:

- **Защита от символических ссылок** — никогда не следует по символическим ссылкам при копировании или удалении
- **Валидация путей** — предотвращение атак path traversal
- **Валидация TrashInfo** — проверка путей из файлов `.trashinfo`
- **Защита от DoS** — ограничения на размер и количество итераций во всех операциях
- **Валидация директорий** — проверка владельца и прав доступа к директории корзины

### Вывод в JSON

Все команды поддерживают флаг `--json` для скриптинга:

```bash
trs list --json | jq '.[] | .name'
trs status --json | jq '.totalSize'
```

## Конфигурация

### Переменные окружения

- `XDG_DATA_HOME` — пользовательская директория данных (по умолчанию: `~/.local/share`)
- `NO_COLOR` — отключить цветной вывод

### Коды выхода

- `0` — Успех
- `1` — Ошибка
- `2` — Некорректное использование

## Сравнение с `rm`

| Возможность | `rm` | `trs` |
|-------------|------|-------|
| Безвозвратное удаление | Да | Нет |
| Корзина | Нет | Да |
| Отмена/восстановление | Нет | Да |
| Безопасность по умолчанию | Нет | Да |
| Соответствие XDG | Нет | Да |
